# TodoList em Pascal

Aplicação de linha de comando para gerenciamento de tarefas, desenvolvida em Pascal durante meus estudos de programação.

## 📋 Sobre o projeto

O TodoList permite cadastrar, listar, concluir e remover tarefas através de um menu interativo no terminal.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de programação e organização de código em Pascal.

## 🚀 Funcionalidades

- Cadastrar tarefas
- Listar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Validação das opções do menu
- Controle da quantidade de tarefas cadastradas

## 🛠️ Tecnologias

- Pascal
- Free Pascal Compiler (FPC)
- Terminal / linha de comando

## 📚 Conceitos praticados

- Variáveis e tipos de dados
- Estruturas condicionais
- Estruturas de repetição
- `record`
- Arrays
- Procedures e Functions
- Entrada e saída de dados
- Validação de dados
